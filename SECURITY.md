# Security

Please report vulnerabilities privately via [Report a vulnerability](https://github.com/legolas-stz/stehauf/security/advisories/new), not as a public issue. Only the latest release is supported.

Sicherheitslücken bitte vertraulich über [Report a vulnerability](https://github.com/legolas-stz/stehauf/security/advisories/new) melden, nicht als öffentliches Issue. Unterstützt wird nur das neueste Release.
